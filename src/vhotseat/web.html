    While something is loaded

    Each row is a workload holding the GPU. Each column is what wants it next. The same three choices everywhere.

    Make room
    1. A request it is answering always finishes first.
    2. It unloads at the first idle moment, in about 2 s. Nothing is closed.
    3. It does not wait for a longer job: an agent between two steps counts as idle.
    Ask me
    1. A notification says when it was last used and asks: unload now, or keep it?
    2. You can pause your work first, then answer.
    3. A workload waits for your answer. A game can't wait, so it runs with what's left until you answer.
    Keep loaded
    1. It stays, and you get a warning.
    2. A workload is refused.
    3. A game can't be refused, so it runs with what's left.
